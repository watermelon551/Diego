# Generic Primitive Reference Note

## Legacy Artifact-First Reference

This note records only reusable observations from legacy artifact-first generation shells.

Observed patterns:
- Several legacy surfaces began with artifact creation rather than session creation.
- Refine behavior was often local and structural rather than full-document regeneration.
- Optional retrieval snippets improved grounded local expansion and summary quality.
- Shell-level concerns such as source binding, selection semantics, preview truth, and library return were tightly coupled around those flows.

Implications for Diego:
- Diego should only absorb behavior that can be named as a host-agnostic generation primitive.
- Local expansion is more reusable than any shell-specific anchor or editor model.
- Grounded partial generation is more reusable than artifact preview, export, or interaction behavior.
- Explicit failure remains better than synthetic success when structured generation or validation fails.

Reference conclusion:
- The useful signal is not any legacy tool label.
- The useful signal is that artifact-first shells repeatedly needed bounded, source-conditioned generation primitives that could operate on a selected content unit.
